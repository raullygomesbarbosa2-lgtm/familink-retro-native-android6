# FamiLink Android nativo

Projeto Android SDK nativo, sem WebView. Min SDK 23 (Android 6.0). O site web continua separado no GitHub Pages.

A primeira build nativa inclui UI Compose, seletor SAF, carregamento de núcleo libretro nativo, SurfaceView/Canvas, AudioTrack, controles por toque e gamepad. Netplay Firebase ainda não está conectado a este aplicativo. ROMs e BIOS não são distribuídas.
